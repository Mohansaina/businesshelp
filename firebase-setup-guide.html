Firebase Setup Guide

Welcome to the Firebase setup guide for your ReviewAI application. This guide will help you configure your Firebase project thebusinesshelper-baccf for use with this application.

Your Firebase Project: thebusinesshelper-baccf

Step 1: Get Your Firebase Configuration

1.1 Access Firebase Console

Go to the Firebase Console and sign in with your Google account.

1.2 Navigate to Project Settings

Click the gear icon ⚙️ next to "Project Overview" in the left sidebar, then select "Project settings".

1.3 Find Your Web App Configuration

In the "General" tab, scroll down to the "Your apps" section:

  • If you see a web app ( icon), click on it to view the configuration
  • If you don't see a web app, you'll need to register one:
    1. Click the "" icon to add a web app
    2. Enter "ReviewAI Web" as the app nickname
    3. Check "Also set up Firebase Hosting" (optional)
    4. Click "Register app"
    5. Copy the configuration code shown

1.4 Configuration Code Example

Step 2: Update Your Application Configuration

2.1 Locate the Configuration File

Open the file public/js/firebase-config.js in your code editor.

Replace the placeholder values in the firebaseConfig object with your actual configuration values:

Step 3: Enable Required Firebase Services

3.1 Enable Authentication

In the Firebase Console:

  1. Click "Authentication" in the left sidebar
  2. Click "Get started"
  3. Go to "Sign-in method" tab
  4. Enable:
    • Email/Password
    • Google
    • GitHub (optional)

3.2 Enable Firestore Database

In the Firebase Console:

  1. Click "Firestore Database" in the left sidebar
  2. Click "Create database"
  3. Select "Start in test mode" (for development)
  4. Choose a location near you
  5. Click "Enable"

3.3 Update Firestore Security Rules

In the Firebase Console:

  1. Go to "Firestore Database"
  2. Click the "Rules" tab
  3. Replace the default rules with:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Allow users to read/write their own data match /users/{userId} { allow read, write: if request.auth != null && request.auth.uid == userId; } // Allow users to read/write their own businesses match /businesses/{businessId} { allow read, write: if request.auth != null && resource.data.userId == request.auth.uid; } // Allow users to read/write their own reviews match /reviews/{reviewId} { allow read, write: if request.auth != null && resource.data.userId == request.auth.uid; } } }

Step 4: Test Your Configuration

4.1 Start Your Development Server

Open a terminal in your project directory and run:

npm start

4.2 Access Your Application

Open your browser and navigate to http://localhost:3000

4.3 Test Authentication

Try the following actions:

  • Click "Sign Up" and create a new account
  • Click "Login" and log in with your credentials
  • Try logging in with Google (if configured)

Troubleshooting

Common Issues and Solutions

  • Console errors about Firebase not initialized: Check that all configuration values are correctly copied
  • Permission denied errors: Verify Firestore security rules are correctly set
  • Authentication not working: Ensure all required sign-in methods are enabled
  • Domain not authorized: Add localhost to authorized domains in Authentication settings
Security Note: The security rules provided are for development only. For production, you should implement more restrictive rules.
