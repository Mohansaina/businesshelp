Get Your Firebase Configuration

Follow these steps to get your Firebase configuration for the project "thebusinesshelper-baccf"

Step 1: Go to Firebase Console

Visit Firebase Console and sign in with your Google account.

Step 2: Select Your Project

Select the project named thebusinesshelper-baccf from the project list.

Step 3: Access Project Settings

Click the gear icon ⚙️ next to "Project Overview" in the left sidebar, then select "Project settings".

Step 4: Find Your App Configuration

In the "General" tab, scroll down to the "Your apps" section. If you don't see a web app ( icon), you'll need to register one:

  1. Click the "" icon to add a web app
  2. Enter "ReviewAI Web" as the app nickname
  3. Check "Also set up Firebase Hosting" (optional)
  4. Click "Register app"
  5. Copy the configuration code shown

Step 7: Enable Required Services

In the Firebase Console, enable these services:
